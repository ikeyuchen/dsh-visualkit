# 工作流：从「看着还行」到「可以验收」

> 一条链路，语料用匿名代号：Colibri / Echo / Flow-Pilot / 旧版 0.5.4。每步写清「问什么 → 用哪个工具 → 实测数字」。

## 五步

| # | 问题 | 工具 | 实测结果（Colibri） |
|---|---|---|---|
| 1 | 有多少问题？ | `taste_check taste` + `layout_check ui` | 26 条，AI 味 53 |
| 2 | 报的到底是不是真的？ | 逐条看 `where`，可疑的放大到 145% 或用 `html_edit scan` 核实 | **19 条是假的** |
| 3 | 哪些能机械改？ | `css_edit snap/scale`、`html_edit rewrite` | 间距 47% → 21%，字号 11 → 5 档 |
| 4 | 哪些要人定？ | — | 色相、毛玻璃、文案取向 |
| 5 | 改完没变坏吧？ | 再跑一次 + `design_render diff` | 均差 1.2%、无整体位移 |

## 三个易错点

| 易错点 | 正确做法 | 实测 |
|---|---|---|
| 先动手、后摸位置 | 替换前先 `html_edit scan kind=emoji`，分开"能换标记的"与"只在属性/脚本里、换了也没用"的；不先扫就把 `<svg>` 写进 `title="…"` 里，整段标记当文本显示 | 32 处、24 种，其中 15 种只在属性/脚本/注释里 |
| 用位图判完成度 | 位图只看极端模板感（图标不成套、字号没层级、文字被裁，放大可见），完成度看源码层 | 26 张截图里位图层只有 1 张报警，那 25 个 0 不是"没问题" |
| 噪声没清零就信分数 | 先修工具，再修界面 | 首轮 26 条里 19 条是工具自己的错：注释 emoji 40 → 12、`getElementById` 按钮 47 → 5、插值空格 13 → 0 |

源码层量出来的是：字号塌缩 1.00× · 间距 38% 不在 4px 网格（含 13.6 / 22.4 非整数像素）· AI 文案 30 处。

## 改造结果

旧版 0.5.4 只动图标/字号/间距、不碰布局与文案：AI 味 27 → **9（clean）**，排版 31 → **18**。

改完的复验命令见 [RELEASING.md](RELEASING.md) 的「发布前检查」：`npm test`、`npm run selfcheck`、`npm run release:check`。
